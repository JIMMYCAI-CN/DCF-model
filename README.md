# DCF 股價估算器（FCFF）— 獨立桌面版

**只做一件事：用 DCF（FCFF）模型估算預計股價。** 其餘（三情景、敏感性、風險標籤、匯出）全部是輔助。

- 面向香港／澳門企業，採用 IFRS 口徑
- Tkinter 桌面 GUI，六步精靈式流程（與 FCFF 資本預算工具同一視覺風格）
- **獨立程式、獨立資料夾**，與專案 NPV 工具完全分離；核心演算模組自原工具原封複製（凍結）

## 啟動

```
雙擊 啟動估價器.bat        （優先用 py，備用 python）
python gui_app.py         （需 Python 3.9+，matplotlib；tkinter 需完整版 Python）
```

## 六步流程

| 步驟 | 內容 |
|---|---|
| 1 公司與財報 | 幣別／單位／稅制（香港兩級利得稅 ⇄ 澳門所得補充稅）；載入示範財報或自備 CSV／JSON |
| 2 基期資料 | 自動從財報帶入營收／EBIT／D&A／CAPEX／營運資金／淨負債／股數／現價；**任何欄位可覆寫，覆寫即鎖定🔒**，「重新抓取財報」只刷新未鎖定欄位 |
| 3 預測設定 | 高速增長年數（預設 5 年）；**逐年成長率／EBIT 利潤率可單獨修改**；永續增長率 g，WACC ≤ g 即時警示＋執行時彈窗禁止 |
| 4 折現率 | 手動 WACC ＋「⚡ 由宏觀模型取得 WACC」；抓取失敗自動降級、保留手動值，不阻斷 |
| 5 情景與敏感性（輔助） | 樂觀／保守偏移幅度可自訂；熱圖範圍可調；全部有預設值，可跳過 |
| 6 執行估值與結果 | **預計股價（主結論）**＋現價對照、風險標籤、四張輔助圖（WACC×g 熱圖、逐年貢獻、三情景、EV 橋接）、逐年表、匯出 JSON／HTML |

## 核心公式

```
FCFF = EBIT × (1 − 有效稅率) + 折舊攤銷 − 資本開支 − 營運資金增量
TV   = FCFF(N) × (1+g) / (WACC − g)
EV   = Σ PV(FCFF) + PV(TV)  →  股權價值 = EV − 淨負債  →  預計股價 = 股權價值 / 股數
```

## 自動風險標籤

- 終值佔 EV > 75%：估值高度依賴永續假設
- g 高於宏觀長期名義 GDP：永續假設偏樂觀
- 歷史財報 < 3 年：樣本不足
- WACC − g < 3pp：差距過小，敏感度高

## 資料夾結構

```
gui_app.py       六步精靈 GUI（本程式主體）
mpl_charts.py    matplotlib 圖表（內嵌 Tkinter）
exporter.py      JSON ＋ 可列印 HTML 報告（攜帶全部參數溯源）
dcfcore/         凍結核心（statements 財報解析／dcf 計算／tax 稅制／macro_analyzer 宏觀參數）
samples/         三份示範財報（香港五年／澳門兩年／香港四年）
output/          匯出檔案
```

## 口徑隔離

本工具為「企業整體 DCF」口徑；企業自由現金流**不會**覆蓋任何專案型 NPV 的增量現金流。
報告（HTML／JSON）內附口徑隔離聲明。

# v2.0 新增頁籤：企業診斷｜四合一（參考校準）

主視窗現有兩個頁籤：**① DCF 股價估值**（原六步精靈，未動）＋ **② 企業診斷｜四合一**。
新頁籤共用同一份財報與稅制設定，五張可收合卡片：

| 卡片 | 內容 |
|---|---|
| ① 杜邦分析 | ROE = 淨利率 × 資產週轉 × 權益乘數；逐年趨勢圖、驅動來源自動判讀、三情景 ROE、歷史 CAGR／EBIT 利潤率導出 |
| ② 信用風險 | Altman Z''-Score（非製造業版，安全／灰色／危險區帶狀圖）＋ 流動／速動／資產負債率／利息覆蓋；缺股價仍可計算並標註 |
| ③ DDM ＋ FCF Yield | Gordon 增長模型（可開關）；Ke 可由宏觀模型取得（失敗降級不阻斷）；Ke ≤ g 禁止計算；無派息自動停用；FCF 收益率對照無風險利率 |
| ④ 可比相對估值 | P/E、P/B、EV/EBITDA、EV/Sales；港股／澳門／A 股樣本池（內建示範池可編輯／CSV 匯入）；中位數反推股價＋溢價／折價；失效指標自動隱藏 |
| ⑤ 綜合摘要 | 四模組結論整合＋與 DCF 內在價交叉對照＋假設偏高／偏低標示 |

## 跨頁籤互動（硬性規則）

- **推送建議值**：杜邦（歷史 CAGR／EBIT 利潤率）與可比（行業中位數）可一鍵推送為 DCF 欄位預設；
  **只套用使用者從未手動修改的欄位**，改過的欄位永遠跳過（推送結果會列出明細）
- **讀取 DCF 對照**：可顯示 DCF 首年增長／利潤率相對歷史與行業「偏高／偏低」，只標示、不修改
- 診斷估值**絕不自動覆寫** DCF 的內在股價；報告內附「參考校準」聲明

## 新增檔案

```
diagnostics.py   四合一引擎（杜邦／Z''／DDM／可比＋情景＋溯源）
diag_charts.py   趨勢折線、Z'' 分區圖、財務比率四小圖、收益率對照、可比箱線圖
diag_tab.py      頁籤 UI（可收合卡片）
diag_export.py   JSON／HTML（全套、單一模組、可附 DCF 報告作驗證附錄）
peers.py         內建可比樣本池（示範資料，可編輯／匯入）
```

# v2.1 自動查詢（免匯入檔案）

第 1 頁新增「① 自動查詢財報」：**輸入股票代號或公司名 → 搜尋 → 抓取並帶入**，
直接從 Yahoo Finance 公開端點抓年度財報、現價、股數，不用再準備任何檔案。

- 支援：港股（`0700`／`0700.HK`）、A 股（`600519.SS`／`000001.SZ`）、美股等；
  也可輸入英文名（Tencent、Sands China）模糊搜尋
- 「常用」下拉內建澳門文旅／博彩、港股藍籌、A 股快捷鍵
- 代號完全相符時自動直接抓取；找不到時保留示範財報與 CSV／JSON 匯入
- 報表幣別自動處理：人民幣／美元記帳的港股，現價會按即時匯率換算成報表幣別
- 12 小時磁碟快取（`cache/`）；「強制更新」勾選可略過快取；斷網時自動改用最近快取並提示
- 抓回的資料走**原本的解析器與 DCF 演算**（dcfcore 一行未動），
  每一科目的對映與推導照樣顯示在第 2 頁，且照樣可人工覆寫＋鎖定
- 企業診斷頁籤新增「🌐 自動抓取同業（Yahoo）」：依 Yahoo 相似公司自動組可比樣本池
  （澳門企業的樣本以港股上市同業計），仍可手動編輯覆蓋
- 已知限制：Yahoo 只提供最近 4–5 個年度；科目為標準化口徑，個別明細與年報原文可能不同
  （介面與報告均標示來源與抓取時間）；ETF／停牌公司可能抓不到

新檔案：`fetcher.py`（抓取核心）、`test_fetch.py`（17 項離線測試；`py test_fetch.py --net` 加測線上）。

# v3.0 港澳估值儀表板升級（測試標的：BOC Aviation 2588.HK）

## ① 營收歷史與成長率
- 杜邦卡片新增「歷年營收與成長率」：逐年 YoY、指數（首年=100）、CAGR、
  最近三年平均成長，並以 **對數線性回歸** 算出營收趨勢增長率（含 R²）
- 新圖 `revenue_trend`：營收柱狀＋成長率折線＋對數趨勢線

## ② 五階杜邦＋EBIT 利潤率獨立輸出
- ROE = EBIT 利潤率 × 利息負擔（EBT/EBIT）× 稅負擔（淨利/EBT）× 資產週轉 × 權益乘數
- EBIT 利潤率**單獨列表**（年度／EBIT／利潤率／行業中位數／差距）並單獨繪圖
- 新圖 `ebit_margin_trend`、`dupont5_factors`（五因子小圖＋ROE 合成）
- 稅前溢利高於 EBIT 的年度（處置收益等非營業項目）會標「†」並解釋，不會誤導

## ③ 三情景打通
- 統一三旋鈕：**營收成長 ±pp／EBIT 利潤率 ±pp／Ke ±pp**（介面可改）
- 同一組偏移同步套用到：五階杜邦、Z''（X3）、DDM（Ke／g）、可比（倍數彈性）、
  DCF（用共用引擎以狀態副本計算三情景股價，**不寫回使用者設定**）
- 三情景橋接表＋`scenario_bridge` 圖；DCF 股價為負時（高槓桿租賃常態）
  改顯示企業價值 EV 對照，並自動嘗試「穩態資本開支＝折舊」重算（明確標示）

## ④ 信用風險保留＋行業備註
- Altman Z''、流動／速動／資產負債率、利息覆蓋全部保留，公式不變
- 航空／設備租賃自動套用**行業調整門檻**（安全 >1.00／灰色 ≥0.40），原始分級照列，
  並輸出調整原因與重點追蹤清單（LTV、債務到期、承租人集中度、航空週期）

## ⑤ 歷史參數自動傳入 DCF／DDM／NPV
- 診斷完成後**自動**把歷史營收成長、EBIT 利潤率寫為 DCF 預設
  （僅使用者從未手動修改的欄位；手動修改永遠不覆蓋）
- DDM 的 g 預設 = min(可持續增長, 名義 GDP, **歷史營收成長**)，並壓在 Ke−3pp 內
- 新增「📤 匯出 NPV 參數包」：歷史成長／EBIT 利潤率／稅制／折現率／情景 → JSON，
  供 NPV 快速估算等外部工具匯入（不會自動覆寫任何工具）

## ⑥ 方向衝突診斷
- 相對估值 vs DDM 方向相反時，自動列出成因（派息率低／高槓桿／週期行業／
  樣本偏少／g 偏高／Ke 降級等）＋處理建議；方向一致時也說明幅度差異

## ⑦ 稅制與折現率
- 稅制一律呼叫 `dcfcore.tax`（預設**澳門所得補充稅**：首 60 萬豁免、超出 12%）；
  報表隱含有效稅率僅作對照
- 折現率 Ke／無風險利率一律由 `dcfcore.macro_analyzer` 輸入；宏觀失敗時降級為
  10% 保守替代並明確標示，不靜默

測試：`py test_diag.py`（48 項，含 BOC Aviation 專項）＋ `py test_fetch.py`（17 項）。
